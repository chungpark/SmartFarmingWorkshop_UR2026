# UR 2026 Workshop Website

This repository contains a GitHub Pages-ready website for the UR 2026 workshop:

**Toward Smart Farming 4.0 and Digital Farming: Challenges and Opportunities in Agricultural Robotics**

## How to publish with GitHub Pages

1. Create a new GitHub repository, for example:
   `ur2026-smart-farming-workshop`
2. Upload all files in this folder to the repository.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: `main`
   - Folder: `/docs`
5. Save. GitHub will provide the public website URL after the Pages build completes.

## What to edit before publishing

Please update these placeholders:

- `docs/index.md`
  - Submission deadline
  - Notification date
  - Camera-ready date, if used
  - Submission link or submission email
  - Confirmed speakers and final program
- `docs/call-for-short-papers.md`
  - Short paper page limits
  - Review policy
  - Publication/archival status
  - Submission link
- `docs/program.md`
  - Speaker names, titles, affiliations, and talk titles
- `docs/organizers.md`
  - Organizer bios, emails, and website links
